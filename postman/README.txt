IMPS API Collection

Import IMPS_API_Collection.postman_collection.json into Postman.

Variables (edit in collection):
  host         - Host IP (e.g. 192.168.1.38 or localhost)
  impsPort     - 8443 (HTTPS) or 8081 (HTTP)
  switchPort   - 8444 (HTTPS) or 8082 (HTTP)
  npciPort     - 8445 (HTTPS) or 8083 (HTTP)

Default profile: prod,ssl. Ports match .env SERVER_PORT in each project.

Sample files: See samples/README.txt for ISO binaries and XML samples.
