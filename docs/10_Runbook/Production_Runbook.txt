# IMPS – Production Runbook

## Start Services

Ensure .env exists in each project (copy from .env.example). Default profile: prod,ssl.

  cd Imps-backend
  mvn spring-boot:run

For mock_switch and mock_npci, run from respective directories.

## Restart

Stop (Ctrl+C) and run mvn spring-boot:run again.

## Log Location

Console output. Log levels from LOGGING_LEVEL_* in .env (prod: INFO).

## Health Check

- ReqHbt: https://localhost:8443/imps/reqhbt/{txnId}
- Heartbeat: IMPS pings switch every 3 min; check logs for UP/DOWN banks

## Common Issues

| Symptom | Check |
|---------|-------|
| Placeholder SPRING_DATASOURCE_PASSWORD | Set in .env (required for prod) |
| Connection refused | IMPS running? socket.enabled: true? Port 9083/9443? |
| Keystore error | SSL_KEY_STORE_PASSWORD in .env; regenerate with certs/generate-certs |
| DB error | PostgreSQL running? imps_db/switch_db exist? |
