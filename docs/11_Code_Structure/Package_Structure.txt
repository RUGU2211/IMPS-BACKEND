# IMPS Backend – Package Structure

## Key Packages

| Package | Contents |
|---------|----------|
| Controllers | ImpsController, NpciController |
| Service | ImpsInboundService, ReqPayService, RespPayService, ReqChkTxnService, etc. |
| Converter | XmlToIsoConverter, IsoToXmlConverter |
| Client | ISwitchClient, RestSwitchClient, SocketSwitchClient, NpciRestClient |
| Config | SslConfig, SocketConfig, NpciSocketConfig, RoutingConfig |
| Socket | NpciSocketServer, SwitchSocketServer, SocketRequestDispatcher, PendingSocketResponseStore |
| Entity / Repository | TransactionEntity, InstitutionMaster, MessageAuditLog |
