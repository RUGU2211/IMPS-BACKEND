## 5. Exception Handling

| Item | Status | Notes / Recommendation |
|------|--------|------------------------|
| Empty catch blocks | **Change** | Empty `catch (IOException ignored) {}` and `catch (InterruptedException ignored) {}` in **mock_npci NpciSocketServer** (3 places); `catch (ISOException ignored) {}` in **mock_switch SwitchSocketServer** (1 place). **Recommendation:** Add `log.debug("Socket close failed", e)` so failures are diagnosable. |
| Custom exceptions | OK | DuplicateTxnIdException, ReqPayValidationException, CommonCodeValidationException, etc. See [09_Error_and_Exception_Handling/Error_Code_Definitions.txt](../09_Error_and_Exception_Handling/Error_Code_Definitions.txt). |
| HTTP status codes | OK | GlobalExceptionHandler returns 400, 409, etc., as appropriate. |
| Error responses standardized | OK | XML error format and RespPay failure structure. |
| Meaningful messages | OK | Exception messages and error payloads are meaningful. |
| Stack trace to user | **Change** | `e.printStackTrace()` used in 10 places: **ReqPayService** (3), **RespPayService** (3), **RespChkTxnService** (3), **TransactionValidationService** (1). Replace with `log.error("message", e)`. GlobalExceptionHandler correctly does not expose stack trace to client. |

**Recommendation:** Replace all `printStackTrace()` with logger calls; add debug log in currently empty catch blocks for shutdown/close.

## Summary of Required / Recommended Code Changes

1. **Security:** Use environment variables (or secret manager) for passwords and keystore credentials in production. `application.yml` currently has `password: root` and `trust-store-password: IMPS-Backend`. Document env vars (e.g. `SPRING_DATASOURCE_PASSWORD`, `SSL_KEY_STORE_PASSWORD`) in [08_Deployment_and_DevOps/Deployment_Guide.txt](../08_Deployment_and_DevOps/Deployment_Guide.txt) or [06_Security/Certificate_Management.txt](../06_Security/Certificate_Management.txt).
2. **Exception handling:** Replace all 10 occurrences of `e.printStackTrace()` with `log.error("description", e)` in: ReqPayService, RespPayService, RespChkTxnService, TransactionValidationService.
3. **Empty catch blocks:** Add `log.debug("...", e)` in: mock_npci NpciSocketServer (IOException x2, InterruptedException), mock_switch SwitchSocketServer (ISOException).
4. **Logging:** Replace `System.out.println` with slf4j logger in TransactionValidationService and AsyncConfig.
5. **Testing:** Add unit tests for ReqPay, RespPay, validation, converters; aim for >70% coverage on business logic.
6. **Optional:** Add Swagger/OpenAPI, retry for external calls.
