NPCI IMPS Message Formats (Reference)


This document is the authoritative format for IMPS API request/response bodies. All bodies in SOCKET_GUIDE.md, IMPS_Req_API_Bodies.md, the Postman collection, and the project code must follow these structures.

---

          msgId=""
          prodType="IMPS"/>

         custRef=""
         refId=""
         refUrl=""
         ts=""
         refCategory=""
         type="PAY|CREDIT"
         purpose=""
         initiationMode=""
         id="">
    </Txn>

    <Payer addr=""
           name=""
           seqNum=""
           type="PERSON|ENTITY"
           code="">

        <Info>
            <Identity id=""
                      type=""
                      verifiedName=""/>
            <Rating verifiedAddress="TRUE"/>
        </Info>

        <Device>
            <Tag name="MOBILE" value=""/>
            <Tag name="LOCATION" value=""/>
            <Tag name="TYPE" value=""/>
            <Tag name="cardAccpTrId" value=""/>
            <Tag name="cardAccIdCode" value=""/>

        <Ac addrType="MOBILE">

            <Detail name="MOBNUM" value=""/>

        </Ac>
